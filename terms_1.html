เอกสารนี้กำหนดข้อตกลงการใช้งานเครื่องมือ/สคริปต์ภายในที่ beearjiw ("เรา") พัฒนาขึ้นเพื่อเชื่อมต่อกับ API ของแพลตฟอร์มโซเชียลมีเดีย (TikTok Content Posting API, YouTube Data API, Facebook Graph API) สำหรับจุดประสงค์เดียวคือการอัปโหลด/ตั้งเวลาเผยแพร่วิดีโอไปยังบัญชีของเราเอง

1. ขอบเขตการให้บริการ

เครื่องมือนี้เป็นเครื่องมือใช้งานภายใน (internal tool) ไม่ได้เปิดให้บุคคลทั่วไปดาวน์โหลดหรือใช้งาน ใช้เพื่อจัดการบัญชีโซเชียลมีเดียของ beearjiw เท่านั้น

2. การใช้งานที่ยอมรับได้

เครื่องมือนี้ใช้เพื่ออัปโหลดเนื้อหาที่ผลิตขึ้นเองหรือมีสิทธิ์ใช้งานถูกต้องตามกฎหมาย (เช่น ภาพข่าวที่เผยแพร่ต่อได้ ภาพ/วิดีโอสต็อกฟรี) เท่านั้น เราจะไม่ใช้เครื่องมือนี้เพื่อสแปม ปลอมแปลงข้อมูล หรือละเมิดนโยบายชุมชนของแพลตฟอร์มที่เชื่อมต่อ

3. ความรับผิดชอบ

ผู้ดำเนินการเป็นผู้รับผิดชอบเนื้อหาที่เผยแพร่ผ่านเครื่องมือนี้แต่เพียงผู้เดียว เครื่องมือนี้เป็นเพียงช่องทางอัตโนมัติในการอัปโหลด ไม่ได้สร้างหรือแก้ไขเนื้อหาโดยอัตโนมัติโดยไม่มีการตรวจสอบจากผู้ดำเนินการ

4. การเพิกถอนสิทธิ์การเข้าถึง

ผู้ดำเนินการสามารถเพิกถอนสิทธิ์การเชื่อมต่อ (revoke API access) ได้ตลอดเวลาผ่านการตั้งค่าของแพลตฟอร์มนั้น ๆ
