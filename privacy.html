นโยบายความเป็นส่วนตัว (Privacy Policy)

ปรับปรุงล่าสุด: 17 กันยายน 2569

เว็บไซต์/แอปพลิเคชันนี้ดำเนินการโดย beearjiw ("เรา") ซึ่งใช้เพื่อจัดการและเผยแพร่คลิปวิดีโอสั้นเชิงข่าว/ข้อมูล (short-form content) ไปยังแพลตฟอร์มโซเชียลมีเดียต่าง ๆ รวมถึง TikTok, YouTube และ Facebook นโยบายนี้อธิบายว่าเราเก็บ ใช้ และคุ้มครองข้อมูลอย่างไร

1. ข้อมูลที่เราเก็บรวบรวม

เราเก็บเฉพาะข้อมูลที่จำเป็นต่อการเชื่อมต่อบัญชีของเราเองกับ API ของแพลตฟอร์มที่เกี่ยวข้อง (เช่น TikTok Content Posting API, YouTube Data API) ได้แก่ โทเคนการยืนยันตัวตน (access token / refresh token) และข้อมูลพื้นฐานของบัญชีที่ใช้เผยแพร่เนื้อหา (เช่น ชื่อช่อง/บัญชี) เราไม่เก็บข้อมูลส่วนบุคคลของผู้ชมหรือผู้ใช้ทั่วไปที่รับชมเนื้อหาของเรา

2. วัตถุประสงค์การใช้ข้อมูล

ข้อมูลที่เก็บไว้ใช้เพื่อวัตถุประสงค์เดียวคือการอัปโหลด/ตั้งเวลาเผยแพร่วิดีโอไปยังบัญชีของเราเองบนแพลตฟอร์มที่เชื่อมต่อไว้เท่านั้น เราไม่นำข้อมูลไปใช้เพื่อการโฆษณา ขายต่อ หรือแบ่งปันกับบุคคลที่สามใด ๆ

3. การจัดเก็บและความปลอดภัย

โทเคนการยืนยันตัวตนถูกจัดเก็บไว้ในเครื่องคอมพิวเตอร์ส่วนตัวของผู้ดำเนินการเท่านั้น ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์สาธารณะหรือแชร์ให้บุคคลอื่น

4. การเปิดเผยข้อมูลต่อบุคคลที่สาม

เราไม่ขาย เช่า หรือแบ่งปันข้อมูลใด ๆ กับบุคคลที่สาม ยกเว้นกรณีที่กฎหมายกำหนด

5. สิทธิ์ของผู้ใช้

ผู้ดำเนินการบัญชีสามารถเพิกถอนสิทธิ์การเชื่อมต่อ (revoke access) ได้ตลอดเวลาผ่านการตั้งค่าความปลอดภัยของแพลตฟอร์มนั้น ๆ (เช่น TikTok Developer Portal, Google Account permissions)

6. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราว การเปลี่ยนแปลงจะประกาศไว้บนหน้านี้พร้อมวันที่ปรับปรุงล่าสุด
